| I-INST-1 | Critical | installers/windows/xephyguard.nsi:196 | `icacls ... /inheritance:r /grant:r ... "*S-1-5-32-545:(OI)(CI)RX"` gives Users inheritable read on `%ProgramData%\XephyGuard`. Later the installer writes `agent.toml` there (line 255), and the agent writes `agent.key`, `agent.crt` and the `[identity] token` there with no ACL of its own (agent/core/src/config.cpp:36-38,117-120; crypto.cpp:145). So any student can read the PC's mTLS key and bearer token. This contradicts the comment at line 189 ("SYSTEM + Administrators only"). | Grant only SYSTEM and Administrators on `%ProgramData%\XephyGuard` (and `data\`). If the helper needs read access, put readable files in a separate subfolder with Users RX. Also set an explicit DACL on key and token files when the agent writes them. |
| I-INST-2 | Critical | installers/ansible/roles/xephyguard_agent/defaults/main.yml:4 | The agent .deb is downloaded over plain `http://` (tasks/main.yml:30-34) with no `checksum:` and no signature check, then installed as root with `apt deb:` (tasks/main.yml:36-38). Anyone on the lab LAN who can intercept traffic (THREAT_MODEL row 22) can get root on every PC the playbook targets. | Download over HTTPS and verify against the already-pinned lab CA (`ca_path`), or require a vaulted `xephyguard_package_sha256` and pass it as `checksum: sha256:...`. |
| I-INST-3 | High | installers/windows/xephyguard.nsi:161 | `CreateDirectory "$COMMONPROGRAMDATA\XephyGuard"` reuses a folder that already exists. | I-INST-4 | High | installers/windows/xephyguard.nsi:255 | `FileOpen ... agent.toml w` overwrites the file on every install or upgrade, which deletes the `[identity]` section (pc_id, token) and the `[paths]` section that the agent saved. | I-INST-7 | Medium | installers/ansible/roles/xephyguard_agent/tasks/main.yml:10 | The CA from HTTP is written to its final path `/etc/xephyguard/ca.crt` before the fingerprint check (line 18-22). | I-INST-9 | Medium | installers/windows/xephyguard.nsi:192 | Any `ca.crt` bundled at build time (line 192) or placed next to the setup exe (`$EXEDIR`, line 193-194) is imported into LocalMachine\Root (line 204) with no comparison to `/CAFP`.
